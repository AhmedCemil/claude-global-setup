One setup, carried to every PC.

This set is the portable master of how you and Claude work together — the rules, the context-saving subagents, the checkpoint skill, the visual drawing canvas. Drop it into ~/.claude on any Windows machine and you're running the same way you do everywhere else.

⚡Install on a new PC

No installer, no code edits. Copy and (optionally) drop in your credentials.

  1. Copy the .claude folder into your home dir

    Unzip the set, then merge its .claude/ into %USERPROFILE%\.claude (i.e. ~/.claude). On Windows that's C:\Users\<you>\.claude — but you never type that; it resolves from $HOME.

    # PowerShell — from inside the unzipped set
Copy-Item .\.claude\* $HOME\.claude\ -Recurse -Force

  2. Add your usage credentials (optional)

    For the live 5-hour limit % readout, copy the template and fill in three values. Skip this and everything else still works — you just won't see the %.

    Copy-Item $HOME\.claude\claude_usage.env.example $HOME\.claude\claude_usage.env
# then edit claude_usage.env → SESSION_KEY / DEVICE_ID / ORG_ID

  3. Confirm it resolves

    Quick smoke test of the limit script (Python required only for this one feature):

    python $HOME\.claude\scripts\claude_limit_percent.py --verbose
# → e.g.  15.0 (resets in 2h44m)

  4. Done

    Launch Claude Code anywhere. CLAUDE.md loads automatically; agents, the skill, and the canvas are available globally.

Why no installer: you asked for files-only. Merging the folder is the install — nothing is generated, nothing is machine-specific.

📐CLAUDE.md — the working rules

Loaded into every session. This is how we work, distilled from long sessions.

How the user thinks

"Is it enough?", simpler-as-can-be, copy-paste-ready, whole-picture-before-parts, mockup-before-code, co-worker not a vending machine. Course corrections come direct — re-align, don't push the old plan.

Critical rules

No default values without permission · ask before implementing missing decisions · preserve naming · no _v2 suffixes · update in place · no speculative scaffolding.

Turkish text

Always use diacritics in user-facing strings · Turkish-safe trLower() · everything through t() · UTF-8 end to end.

Error protocol

Root cause over symptom · keep the suite green · no destructive shortcuts (--no-verify, git reset --hard) to make obstacles vanish.

Context-window discipline

Main chat = orchestrator (Opus). Push grunt work to cheaper subagents to protect the 5-hour window. Safety valve: main chat outranks a shallow subagent result.

Memory model

No global memo. One MEMORY.md per project, in the project's own folder. Facts only — never the memory rule itself.

Stay in the given folder: don't read/search/cd into dirs other than the one you were pointed at — sibling code bloats context and applies the wrong conventions.

🐍CLAUDE - Python.md

Read on top of CLAUDE.md when the project is Python. The build know-how, kept; the machine paths, dropped.

Deployment

Per-project requirements.txt; Nuitka-friendly imports so every project ships as a single exe.

Structure

src/ui · core · config; main.py coordinates, doesn't implement; core never imports UI.

UI

CustomTkinter only · Material Design 3 palette · compact density · one theme.py owns all tokens.

Windows console

Pipe Unicode/Turkish output through a unicode converter so it doesn't degrade to ?.

Intentionally removed: machine-specific bits like a fixed shared-.venv location and project-specific exceptions. The Python workflow travels; where the venv lives does not.

🤖Subagents

Stack-aware helpers that keep big output out of the main context. Spawn by type, don't re-describe.

co-explorer sonnet · read-only

Codebase walks and "where/how is X" searches. Returns a tight conclusion + 2–5 file:line refs, not file dumps. Detects Go/JS vs Python from one listing. Stays in the active project.

co-tester sonnet · runs cmds

Runs builds/tests/e2e and reports a verdict — PASS/FAIL, counts, trimmed failures — not a transcript. Won't cheat red→green. Uses the project's venv, never system Python.

💾save-session-state

Checkpoint the session + report how close you are to the 5-hour wall.

On "save state" / "checkpoint" / a milestone, the skill: reads the live 5h limit %, then appends a short timestamped block to the active project's MEMORY.md so a fresh session resumes cleanly after compaction or a rate-limit reset.

# the % comes from this portable call (no drive path)
python ~/.claude/scripts/claude_limit_percent.py --verbose
# Saved at 14:20. 5h limit at 15.0% (resets in 2h44m).
Fails soft: if credentials are missing the checkpoint still saves — you just lose the % line.

🎨Shared drawing canvas

A two-way visual channel for when words get fuzzy on a layout or interaction.

Claude sketches a proposal on the base layer; you draw corrections on the transparent user layer; both persist in localStorage. Driven over a debug-port Chrome (--remote-debugging-port=9333). Animations run locally via one requestAnimationFrame loop — essentially token-free, so Claude can make an interaction move before any code is written.

🔑The usage .env

Personal session credentials — kept out of the set, kept off any shared zip.

Three keys power the 5h limit readout: SESSION_KEY, DEVICE_ID, ORG_ID. The set ships only claude_usage.env.example (empty). Your real file lives at ~/.claude/claude_usage.env, fully decoupled from any project folder.

Security: never put the filled-in .env in the zip you share — it's a live session token. Only the .example belongs in the set.

🧭Portability rules (how this stays PC-agnostic)

No absolute paths

Everything resolves from $HOME / ~ or the script's own location (__file__). Grep the whole tree for a drive letter → zero matches.

.env found by search

The limit script checks $CLAUDE_LIMIT_ENV → ~/.claude/claude_usage.env → next-to-script. First found wins. New machine = drop the file, done.

No dead projects

All project-specific and work-only references stripped. Rules are project-agnostic; project detail lives in each project's own files.

Win11 + PowerShell

The one environment assumption — true for all your PCs. The only place it's stated is the CLAUDE.md header.
